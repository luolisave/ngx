# ngx
This is a fullstack demo project

## Frontend
folder: ./my-ng-21
Command to run: 
~~~batch
npm run start
~~~
Command to build:
~~~batch
// build datetime under UI right bottom conner
npm run build  
~~~


## Backend
folder: ./server
Command to install:
~~~batch
node install.js  // will add user admin:pass1234 in db
~~~

Command to run: 
~~~batch
// backend use /my-ng-21/dist/my-ng-21/browser when exist
// or use ./public when above folder not exist.
node index.js
~~~
